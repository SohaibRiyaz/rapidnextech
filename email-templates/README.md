# Introduction emails: how to use them

These are short, personal introduction emails from Dr. Nimr to K Gulf Hosting customers. Each one links to a RapidNexTech page for the customer's type of business.

These files are not part of the website. They are only here so they can be copied into an email.

## Which file to use

| Customer type | With merge fields | For one-off manual sending |
| --- | --- | --- |
| Any business (general) | `general.html` | `general-no-merge.html` |
| Small and growing businesses | `business-websites.html` | `business-websites-no-merge.html` |
| Shops, retailers and distributors | `ecommerce-retail.html` | `ecommerce-retail-no-merge.html` |
| Larger companies and IT firms | `enterprise-it.html` | `enterprise-it-no-merge.html` |
| Charities and non-profits | `nonprofits.html` | `nonprofits-no-merge.html` |
| Finance, leasing and accounting firms | `financial-services.html` | `financial-services-no-merge.html` |

Every `.html` file has a matching `.txt` file with the same email as plain text. Use the `.txt` file if your email program can't send formatted emails, or if you'd rather type the email yourself.

**Subject line.** The suggested subject is on the first line of each `.txt` file. In the `.html` files it is in a comment near the top.

## Merge fields (only in the files without "no-merge")

Two placeholders need replacing before you send:

- `{{FirstName}}`: the customer's first name, e.g. `Ahmed`
- `{{CompanyName}}`: the customer's company name, e.g. `Al Noor Trading`. It appears in the subject, the first paragraph **and inside the button link**.

**In the button link**, write the company name with `+` instead of spaces and `%26` instead of `&`. For example:

- `Al Noor Trading` becomes `Al+Noor+Trading`
- `Smith & Co` becomes `Smith+%26+Co`

The page the customer opens will then show **"Prepared for Al Noor Trading"** at the top. Only the customer sees this; search engines never index it.

If you use a mail-merge tool (for example a Gmail or Outlook mail-merge add-on), map `{{FirstName}}` and `{{CompanyName}}` to the matching columns in your customer list.

If you are writing to one customer by hand, the **no-merge** files are easier: they have no placeholders and you can send them as they are, or add the person's name after "Hello".

## Edit the opening line

The first paragraph ("As one of our valued K Gulf Hosting customers…") is a suggestion. Change it to whatever suits the relationship, for example to mention when you last spoke.

Please keep the rest of the wording as it is. It only describes what is on the RapidNexTech website.

## How to open a file

1. Double-click the `.html` file. It opens in your web browser and shows the email exactly as it will look.
2. To read or edit the plain-text version, open the `.txt` file in Notepad (Windows) or TextEdit (Mac).

## How to paste into Gmail

1. Open the `.html` file in **Google Chrome**.
2. Press **Ctrl+A** (Mac: **Cmd+A**) to select everything, then **Ctrl+C** (Mac: **Cmd+C**) to copy.
3. In Gmail, click **Compose** and click in the message area.
4. Press **Ctrl+V** (Mac: **Cmd+V**) to paste. The formatting and the blue button are kept.
5. Copy the subject line from the `.txt` file into the **Subject** field.
6. Replace `{{FirstName}}` and `{{CompanyName}}` in the text.
7. To fix the button link, click the button, choose **Change**, and replace `{{CompanyName}}` in the web address (see "Merge fields" above).

## How to paste into Outlook

1. Open the `.html` file in **Microsoft Edge** or **Chrome**.
2. Select everything (**Ctrl+A**) and copy (**Ctrl+C**).
3. In Outlook, create a **New Email** and paste (**Ctrl+V**) into the message area.
4. Add the subject line, then replace the placeholders.
5. To fix the button link, right-click the button, choose **Edit Link**, and replace `{{CompanyName}}` in the address.

If the button turns into plain underlined text, the email will still work: the link is the same.

## Always send a test to yourself first

Before writing to a customer:

1. Send the finished email to your own address.
2. Open it on your computer and on your phone.
3. Check that the name and company are filled in everywhere and no `{{` placeholders are left.
4. Click the button and check that the page opens and shows "Prepared for" with the right company name.

## What the link contains

Each button link includes `ref=kgulf` and `utm_…` codes. These let RapidNexTech see that the visitor came from your introduction. They are not shown to the customer on the page.

## For developers

The emails are generated by `scripts/build-email-templates.mjs`. To change the wording, edit that script and run:

```bash
node scripts/build-email-templates.mjs
```
